## 已实施：手机端首屏改竖向流式（≤900px 起）
- 用户拍板：接受照片变矮；≤900px 与 ≤640px 一起改；卡片与照片同宽；卡片不再用毛玻璃。间距值由我定 —— 照片↔卡片 **20px**，卡片↔信任条沿用既有 `clamp(48px,5vw,72px)`（手机上取 48px）。
- 改动全部落在 `src/style.css` 的三处断点：
  - **≤900px**：`.hero-art { min-height: auto; max-height: none; margin-inline: auto; }`；`.hero-copy { position: static; width: min(var(--content-width), calc(100% - var(--hero-gutter))); margin: 20px auto 0; background: var(--surface); backdrop-filter: none; }`；新增 `.hero-index { display: none; }`。
  - **≤640px**：整条 `.hero-art` 覆写**删除**（改为继承 ≤900px 的 16:9）；`.hero-copy` 只保留 `padding: 22px 19px`。
  - **≤380px**：删掉 `.hero-art { min-height: 820px }` 和两条 `.hero-copy` 的 top/left/width，只留 padding 与 h1 字号。
- 核心原理：DOM 顺序本来就是 `.hero-art` → `.hero-copy`，卡片一回到文档流就自带正确顺序；`.trust-strip` 在 `.hero-section` 之外，被自然顶下去 —— **覆盖问题从根上消失**，不再需要靠调 `top` 去躲。
- ⚠️ 必须连带复位 `min-height`/`max-height`：基础的 `min-height: 540px` 会把 16:9 容器顶高，多出的高度再被 `cover` 裁掉。只删 `aspect-ratio` 覆写是不够的（`.hero-art-frame` 还有 `min-height: inherit`，会跟着父级走）。
- 验证脚本 `.verify/shots.cjs`（自起静态服务 + playwright-core，四档视口）：390×844 浅/深、360×780、820×1180、1360×900。结果：手机与平板 `artRatio` 恒为 1.778、`copyPosition: static`、`sameWidth: true`、间距 20/48、深色卡片背景 `rgb(33,29,46)`；桌面档仍是 `absolute` + `blur(10px)` + `min-height: 540px` + `.hero-index: flex` —— **桌面零回归**。
- 代价（用户知情接受）：手机上照片仅约 202px 高（原 720px），首屏放不下「照片+卡片+信任条」，需下滚。
- 连带变化：`.hero-index` 角标现在 ≤900px 起全部隐藏（原先只在 ≤640px 隐藏），因为流式下它会脱离照片下缘、落到卡片下方的空白里。
- 遗留未处理：`.hero-placeholder`（无照片时的占位）在 ≤640px 仍沿用为 720px 高容器调的百分比位置，现在容器只有约 202px 高，理论上会偏挤；站点有真实照片，暂未验证。

## 已实施：桌面端窄窗口下首屏左右溢出（方案 A）
- 现象（用户："从电脑端长度再缩小一点，卡片左边和右边都会被遮挡"）：窗口一窄，**文字卡片左边**与**首屏照片右边**同时被 `.site-shell { overflow: clip }` 裁掉。
- 实测（`scrollbar-gutter: stable` → clientWidth = 窗口宽 - 10）：
  - 卡片左缘：窗口 <1380px 时 `left` 算成负数 —— 1366 裁 7px、1300 裁 40px、≤1200 恒裁 42px。
  - 照片右缘：<1390px 起一路出屏 —— 1300 溢 28px、1200 溢 62px、1024 溢 41px、960 溢 38px，直到 900px 才结束。
  - 桌面端「错位构图」的**存活阈值 ≈ 1380/1390px**，两处溢出是同一个"空间不够"引起的。
- 根因（两处公式一处没设限、一处少算）：
  1. `.hero-art` 的 `width: min(1200px, calc(100% - var(--hero-gutter)))` **漏减了 `--hero-overlap`**，而它的左边距是 `gutter + overlap`；过约束时 CSS 丢弃 `margin-right`，于是照片右缘必出屏。
  2. `.hero-copy` 的 `left: calc(max(48px, (100vw - 1200px)/2) - 90px)`：`max()` 里的 48px 在窗口 <1380px 时恒取 48 → 48-90 = **-42px**。
  3. 兜底断点 ≤1100px 才开始，且那一档 `--hero-overlap` 仍是 `clamp(48px,5vw,76px)`（没归零）→ 900–1100 区间只修了卡片、**照片照样被裁**。
- 修法（用户选方案 A：两条公式加"空间上限"）：
  - `.hero-art` 宽度 → `min(var(--content-width), calc(100% - var(--hero-gutter) - var(--hero-overlap)))`
  - `.hero-copy` left → `max(48px, calc(max(48px, (100vw - 1200px) / 2) - 90px))`（48px 下限刻意与全站 `.section` 边距对齐）
- 验证脚本 `.verify/hero-width.cjs`：12 档宽度 901→1600 逐档测量 + 截图；**`FIX=1` 环境变量可在完全不改仓库文件的前提下注入候选样式预演效果**（`page.addStyleTag`）——这套"先注入验证再落地"的流程很适合这类几何改动。
  - 1600px 与改动前**逐像素一致**（copy L=110、art L=296 R=1496 w=1200）
  - 1440px 卡片左缘 30→48（+18px，桌面端唯一变化）；≥1500px 完全不变
  - 901–1380 不再溢出：卡片 L 恒 ≥48，照片 R 恒 == clientWidth
  - `.verify/shots.cjs` 四档回归：手机/平板数据与上一轮完全一致，桌面档仍 `absolute` + `blur(10px)` + `min-height:540px` + `.hero-index: flex`
- 遗留：修复后照片右缘在 901–1380px 区间**贴着窗口右边缘**（0px 间隙、圆角可见），是原设计「右移 overlap + 右边距被丢弃」的自然延续，非新问题。

## 追加：给首屏照片右缘留间距（新增 `--hero-right-gap`）
- 用户（09-27 下午）："不要首屏照片右缘与窗口齐平，要与右边有间距。"
- 新增第三个变量 `--hero-right-gap` 并入 `.hero-art` 宽度表达式：`min(var(--content-width), 100% - gutter - overlap - right-gap)`。
  - 取值刻意抄正文栏 `.section` 的左右边距：**>1100px = 48px**（section 是 `100% - 96px`）、**≤1100px = 32px**（是 `100% - 64px`）、**≤900px = 0px**（单栏流式照片居中，必须归零，否则手机照片会比下方卡片窄）。
  - ⚠️ 不能指望本来就写着的 `margin-right: var(--hero-gutter)` 去兜 —— 过约束时 CSS 直接丢弃 margin-right。
  - ⚠️ reserve 也**不能取 `--hero-gutter`**：它在宽屏会无上限变大（1600px 时 =200px），会把照片从 1200 压到 1094，破坏 >1470px 的现有版式。固定 48px 才能只影响窄窗口。
- 实测（`.verify/hero-width.cjs`，日志已新增「右间距」列）：≥1471px 完全不变（1600：w=1200、右间距 104）；**1440：w 1200→1175.6、右间距 33.6→58（本轮唯一的桌面端变化）**；1101–1440 右间距恒 58；901–1100 恒 42；≤900 归 0。
  - 实测值比标称多 10px 是正常现象：`100vw` 含滚动条而 `100%` 不含（headless 下 `documentElement.clientWidth` 报 1600、布局宽实际 1590）。与正文栏的对齐关系是对的。
- `.verify/shots.cjs` 四档回归：手机/平板完全不变（art L=10/w=360、L=20/w=770、ratio 1.778、static、间距 20/48）；桌面 1360 档 art w 1188.4→1140.4、copy L=48、仍 `absolute` + `min-height: 540px`。
